Student Life Balance

Student Life Balance is a multi-page website created to help students explore practical ways to balance academics, routines, hobbies, study environments, and useful study tools.

Project Overview

The website provides information about different parts of student life and uses multiple HTML pages, images, and clickable visual elements to make the content easy to explore.

Some interactive images link users to related sections of the website, such as:

a clock linking to the daily routine page

a study spot image linking to study environment information

a laptop image linking to useful study tools

Main Pages

index.html — Home page

about.html — About the project

routine.html — Student routine and time-balance information

studyspots.html — Study environment and study-spot information

tools.html — Useful tools for students

tips.html — Student life balance tips

hobbies.html — Hobbies and personal-life balance

gallery.html — Project image gallery

feedback.html — Feedback page

citations.html — Sources and citations
